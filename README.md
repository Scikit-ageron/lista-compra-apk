# Lista de la compra · APK

Descargas de la app familiar de lista de la compra, básicos de casa y gastos.

**Descargar la última versión:** en [Releases](../../releases/latest), archivo `ListaCompra.apk`.

Instalar en Android: abrir el archivo → si avisa, «Permitir de esta fuente» → «Instalar».
Si Chrome dice que el archivo puede ser dañino, «Descargar igualmente».

El código fuente es privado; aquí solo se publican las APKs.
